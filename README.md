# AI_Project — Sistema de recomendación

## 1. Introducción

El proyecto consiste en desarrollar un sistema de recomendación de películas utilizando Python y GitHub Copilot como herramienta de apoyo a la programación.

## 2. Objetivo

Explorar las capacidades de la inteligencia artificial generativa para apoyar la creación de código y desarrollar un programa que recomiende películas según los géneros favoritos del usuario.

## 3. Herramientas utilizadas

- GitHub.
- GitHub Copilot.
- Visual Studio Code.
- Python.
- Git.

## 4. Desarrollo de la actividad

### 4.1 Creación del repositorio

Se creó un repositorio llamado AI_Project en GitHub para almacenar los archivos del proyecto.

### 4.2 Clonación del repositorio

Se clonó el repositorio en el equipo local y se abrió mediante Visual Studio Code.

### 4.3 Generación del código

Se creó el archivo recommendation_system.py y se utilizó GitHub Copilot para apoyar la generación del código inicial.

### 4.4 Ejecución y pruebas

Se ejecutó el programa desde la terminal de Visual Studio Code. Como prueba, se ingresaron los géneros acción, comedia y ciencia ficción. El sistema mostró las películas Risas en la oficina y Un día inesperado, ambas asociadas al género comedia.

## 5. Evidencias

Se incorporarán capturas de pantalla de la creación del repositorio, la clonación, la generación del código con Copilot y la ejecución del programa.

## 6. Conclusión

La actividad permitió aplicar GitHub Copilot como herramienta de apoyo al desarrollo de software. Se comprobó que puede ayudar a generar código inicial y que es necesario ejecutar y revisar el programa para verificar sus resultados.
